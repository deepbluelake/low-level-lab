# Low-Level Lab

> A collection of hands-on C++ experiments exploring operating systems, concurrency, networking, memory management, Linux internals, and computer architecture.

## Why?

This repository is my personal systems programming playground. Instead of just reading theory, every concept is backed by runnable code and notes.

The goal is to understand **how things work under the hood** and try to implement them.

```

## Build

Most examples can be compiled using:

```bash
g++ -std=c++20 main.cpp -pthread -o app
./app
```
Some examples may use CMake.
